# 271. Encode and Decode Strings

## Topics
- Array
- String
- Design

## Difficulty
Medium

## Complexity
- Time:
    - Encoding: O(n + m)
    - Decoding: O(m)
- Space:
    - Encoding: O(m)
    - Decoding: O(n + m)

>n = number of strings   
>m = total characters in all strings.
