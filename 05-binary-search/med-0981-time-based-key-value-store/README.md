# 981. Time Based Key-Value Store

## Difficulty
Medium

## Complexity
- Time: O(s * 1 + g * log(n))
- Space: O(s)

> `s` is the number of set operations
> `g` is the number of get operations
> `n` is the maximum number of timestamps associated with a single key
